01 int vs float — and when it matters
✓
Mark done

Python has three numeric types: int, float, and complex. For the vast majority of work, you'll use the first two. Knowing the difference prevents silent bugs in calculations.

🔁 Think in terms of money and change

An integer is like a bank note — whole, complete, no fractions. You have 5 notes or 20 notes. Never 5.5 notes.

A float is like an amount in a bank account — it can have cents. You have 1,250.75. The decimal part is precise and significant.

Whenever you do real-world calculations (prices, percentages, measurements), you almost always want floats. When you're counting discrete things (students, iterations, items), you want integers.

🟡 int and float behaviour — run this and study the outputs
# Integers: no decimal point, no upper limit in Python
students = 32
year = 2024
very_large = 10 ** 100    # Python handles huge integers natively
print(very_large)            # 10000...000 (a googol)

# Floats: always have a decimal point
price = 14.99
pi = 3.14159
rate = 0.075               # 7.5%

# The type check
print(type(10))             # <class 'int'>
print(type(10.0))           # <class 'float'>
print(type(10 / 2))         # <class 'float'> — division ALWAYS returns float
print(type(10 // 2))        # <class 'int'>   — floor division returns int

# int and float can mix — result becomes float
result = 5 + 2.0
print(result)                # 7.0 — int + float = float
print(type(result))          # <class 'float'>

# Underscores in large numbers (Python 3.6+)
population = 1_400_000_000  # 1.4 billion — easier to read
print(population)            # 1400000000
🚨 Float precision is not perfect

Floats in Python (and most programming languages) use binary floating-point representation. Binary can't represent all decimal fractions exactly — similar to how 1/3 can't be written exactly in decimal.

This causes small precision errors:

print(0.1 + 0.2)  # 0.30000000000000004 — not 0.3!

For most purposes this doesn't matter. When precision matters (financial calculations), use Python's decimal module or round your outputs with round().

Python gives you seven arithmetic operators. You'll use five of them constantly. The other two (// and %) are less obvious but extremely useful once you know what they're for.

OperatorNameExampleResultWhen to use it

🟡 All 7 operators with practical examples
a = 17
b = 5

print(f"Addition:       {a} + {b} = {a + b}")    # 22
print(f"Subtraction:    {a} - {b} = {a - b}")    # 12
print(f"Multiplication: {a} * {b} = {a * b}")    # 85
print(f"True division:  {a} / {b} = {a / b}")    # 3.4
print(f"Floor division: {a} // {b} = {a // b}")  # 3  (how many 5s fit in 17?)
print(f"Modulo:         {a} % {b} = {a % b}")    # 2  (what's left over?)
print(f"Exponent:       {a} ** {b} = {a ** b}")  # 1419857

Floor division and modulo — the underrated pair

These two are confusing at first but come up constantly. Let's demystify them.

🟡 Floor division (//) and modulo (%) explained
# Floor division (//) answers: "how many times does divisor fit completely?"
# It DISCARDS the remainder — always rounds DOWN (toward negative infinity)
print(17 // 5)    # 3  — 5 fits into 17 exactly 3 times
print(20 // 4)    # 5  — evenly divisible
print(7 // 2)     # 3  — not 3.5, rounds DOWN
print(-7 // 2)    # -4 — rounds DOWN (toward -infinity, not zero!)

# Modulo (%) answers: "what's the remainder after dividing completely?"
# 17 = (5 * 3) + 2 → 17 // 5 = 3,  17 % 5 = 2
print(17 % 5)     # 2 — remainder
print(20 % 4)     # 0 — divides evenly, no remainder
print(7 % 2)      # 1 — odd number leaves remainder 1

# PRACTICAL USE 1: Check even or odd
number = 42
if number % 2 == 0:
    print(f"{number} is even")
else:
    print(f"{number} is odd")

# PRACTICAL USE 2: Convert seconds to hours, minutes, seconds
total_seconds = 3723
hours = total_seconds // 3600
remainder = total_seconds % 3600
minutes = remainder // 60
seconds = remainder % 60
print(f"{total_seconds} seconds = {hours}h {minutes}m {seconds}s")
# 3723 seconds = 1h 2m 3s

# PRACTICAL USE 3: Pagination — how many full pages of 10 items?
total_items = 47
page_size = 10
full_pages = total_items // page_size    # 4
remaining = total_items % page_size      # 7 items on the last page
print(f"{full_pages} full pages + {remaining} items remaining")

Exponentiation — powers

🟡 The ** operator
# Squares and cubes
print(4 ** 2)    # 16   — 4 squared
print(3 ** 3)    # 27   — 3 cubed
print(2 ** 10)   # 1024 — 2 to the power of 10

# Square root = raise to the power of 0.5
print(25 ** 0.5)  # 5.0  — square root of 25
print(64 ** 0.5)  # 8.0

# Nth root = raise to the power of 1/N
print(27 ** (1/3))  # ≈3.0 — cube root of 27

# Compound interest formula: P * (1 + r)^n
principal = 10000
rate = 0.08        # 8% annual
years = 5
future_value = principal * (1 + rate) ** years
print(f"Future value: KES {future_value:,.2f}")  # KES 14,693.28

03 Operator precedence (PEMDAS)
✓
Mark done

When an expression has multiple operators, Python follows a specific order to evaluate them — exactly like the maths rule you learned in school: PEMDAS (Parentheses, Exponents, Multiplication/Division, Addition/Subtraction). In Python, this same order applies.

PriorityOperatorsDescription
1 (highest)()Parentheses — evaluated first, always
2**Exponentiation
3* / // %Multiplication and division (left to right)
4 (lowest)+ -Addition and subtraction (left to right)
🟡 Precedence in action — predict each result before running
# No parentheses — Python uses precedence rules
print(2 + 3 * 4)       # 14  — * before +, so 3*4=12, then 2+12=14
print(10 - 2 ** 3)      # 2   — ** first, so 2^3=8, then 10-8=2
print(6 + 4 / 2)        # 8.0 — / first, so 4/2=2.0, then 6+2.0=8.0
print(15 // 2 + 4 % 3) # 8   — // and % first: 7 + 1 = 8

# Parentheses override everything — add them to be explicit
print((2 + 3) * 4)      # 20  — now + happens first
print(10 - (2 ** 3))    # 2   — same result but more explicit

# Real example: salary formula without vs with parentheses
salary = 5000
bonus_pct = 0.1   # 10%
tax_pct = 0.2     # 20%

# WRONG: taxes applied before adding bonus
wrong = salary + salary * bonus_pct - salary * tax_pct
print(f"Wrong calculation: {wrong}")  # Actually gets right answer here by chance

# RIGHT: use parentheses to make your intention clear
gross = salary * (1 + bonus_pct)    # salary + 10%
net = gross * (1 - tax_pct)          # take off 20% tax
print(f"Gross: {gross}, Net: {net}")
Rule of thumb: when in doubt, add parentheses. They make your code more readable AND guarantee the correct order. Nobody loses points for being explicit.

04 Augmented assignment operators
✓
Mark done

Augmented assignment operators are a shorthand: they apply an arithmetic operation to a variable and save the result back into the same variable, all in one step.

🟡 Long form vs shorthand — they do the same thing
counter = 0

# Long form (works, but repetitive)
counter = counter + 1   # add 1, store back in counter
print(counter)          # 1

# Augmented shorthand (same thing, cleaner)
counter += 1            # means: counter = counter + 1
print(counter)          # 2

# All augmented assignment operators
x = 10
x += 3    # x = 10 + 3 = 13
x -= 2    # x = 13 - 2 = 11
x *= 2    # x = 11 * 2 = 22
x /= 4    # x = 22 / 4 = 5.5
x **= 2   # x = 5.5 ** 2 = 30.25
x //= 3   # x = 30.25 // 3 = 10.0
x %= 3    # x = 10.0 % 3 = 1.0
print(x)   # 1.0

# Practical: accumulate a total
total = 0
total += 250    # First purchase
total += 89     # Second purchase
total += 1200   # Third purchase
print(f"Total spent: KES {total:,}")  # KES 1,539
+= is the one you'll use most — it appears in nearly every loop that accumulates a count or sum. Memorise it immediately.

05 Built-in number functions
✓
Mark done

Python includes several built-in functions (no import needed) that work directly on numbers.

🟡 Built-in number functions
# abs() — absolute value (always positive)
print(abs(-42))       # 42
print(abs(-3.7))      # 3.7
print(abs(100))        # 100  — already positive, unchanged
# Use case: distance is always positive regardless of direction
temperature_change = -8
print(f"Change magnitude: {abs(temperature_change)} degrees")

# round() — round a float to N decimal places
print(round(3.7))        # 4   — rounds to nearest int
print(round(3.2))        # 3
print(round(3.5))        # 4   — Python rounds 0.5 UP
print(round(3.14159, 2))  # 3.14 — 2 decimal places
print(round(3.14159, 4))  # 3.1416 — 4 decimal places

# max() and min() — largest and smallest values
print(max(10, 25, 7, 43, 12))   # 43
print(min(10, 25, 7, 43, 12))   # 7

# sum() — adds up all items in a sequence
scores = [87, 92, 78, 95, 83]
print(sum(scores))          # 435
average = sum(scores) / len(scores)
print(f"Average: {average:.1f}")  # Average: 87.0

# pow(base, exp) — same as ** but can take a third argument for modulo
print(pow(2, 10))         # 1024
print(pow(2, 10, 1000))   # 24  — (2^10) % 1000 = 1024 % 1000 = 24

06 The math module
✓
Mark done

For more advanced maths, Python has a built-in math module. Module just means a file of extra tools — you have to import it before you can use it. Modules are covered fully in Phase 5, but you'll start using math right away.

🟡 The math module — most useful functions
import math   # This line makes all of math's tools available

# --- Square root ---
print(math.sqrt(25))       # 5.0
print(math.sqrt(2))        # 1.4142... — irrational number

# --- Floor and ceiling (rounding direction control) ---
print(math.floor(3.9))     # 3 — round DOWN (always)
print(math.ceil(3.1))      # 4 — round UP (always)
print(math.floor(-3.2))    # -4 — floor goes toward -infinity
print(math.ceil(-3.9))     # -3 — ceil goes toward +infinity

# --- Mathematical constants ---
print(math.pi)              # 3.141592653589793
print(math.e)               # 2.718281828459045 (Euler's number)
print(math.inf)             # inf  — positive infinity
print(-math.inf)            # -inf — negative infinity

# --- Area of a circle ---
radius = 7
area = math.pi * radius ** 2
print(f"Area: {area:.2f} cm²")  # Area: 153.94 cm²

# --- Factorial (n! = n × n-1 × n-2 × ... × 1) ---
print(math.factorial(5))   # 120  (5! = 5×4×3×2×1)
print(math.factorial(10))  # 3628800

# --- Logarithms ---
print(math.log(100, 10))    # 2.0  — log base 10 of 100
print(math.log2(8))         # 3.0  — log base 2 of 8
print(math.log(math.e))     # 1.0  — natural log (ln) of e
You now know every arithmetic operator Python has, how they interact with int and float, the order Python evaluates them, and a library of functions for advanced calculations. This is the full mathematical toolkit for Phase 1 and well into the rest of the course.

🎯 Challenge — Invoice Calculator

Build a simple invoice calculator using everything from this lesson.

Given: unit_price = 1200.0, quantity = 7, vat_rate = 0.16, discount_pct = 0.05 (5%)

1. Calculate subtotal: unit_price * quantity
2. Apply discount to subtotal
3. Calculate VAT on the discounted subtotal
4. Calculate total (discounted subtotal + VAT)
5. Calculate how many full payments of KES 2,000 this total requires and how much is left over
6. Print a formatted invoice with all values rounded to 2 decimal places and formatted with comma separators

🟡 Solution
# Given values
unit_price = 1200.0
quantity = 7
vat_rate = 0.16
discount_pct = 0.05

# Calculations
subtotal = unit_price * quantity                 # 8400.0
discount = subtotal * discount_pct              # 420.0
discounted = subtotal - discount                 # 7980.0
vat = discounted * vat_rate                      # 1276.8
total = discounted + vat                         # 9256.8

payment = 2000
full_payments = int(total) // payment            # 4
balance = total - (full_payments * payment)      # 1256.8

# Invoice output
print("=" * 35)
print("INVOICE SUMMARY")
print("=" * 35)
print(f"Unit Price:   KES {unit_price:>10,.2f}")
print(f"Quantity:     {quantity:>14}")
print(f"Subtotal:     KES {subtotal:>10,.2f}")
print(f"Discount:     KES {discount:>10,.2f}")
print(f"VAT (16%):    KES {vat:>10,.2f}")
print("=" * 35)
print(f"TOTAL:        KES {total:>10,.2f}")
print(f"Full KES 2K payments: {full_payments}, Balance: {balance:,.2f}")

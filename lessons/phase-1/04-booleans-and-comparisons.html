01 True and False — the basics
✓
Mark done

🔁 Think of a light switch

A boolean is the simplest possible thing in programming: it has exactly two states. On or off. Yes or no. Allowed or denied. In Python, these two states are called True and False.

Every decision your code makes — "should I run this block?", "has the user paid?", "is this password correct?" — ultimately gets evaluated to one of these two values. Booleans are the language of logic.

is_logged_in
True ✓
has_paid
False ✗
account_active
True ✓
is_banned
False ✗
🟡 Booleans — run this and observe
# Boolean values: EXACTLY two options
# Capital T, capital F — case matters in Python
is_active = True
is_banned = False

print(is_active)          # True
print(is_banned)          # False
print(type(is_active))    # <class 'bool'>

# Booleans are created naturally by comparisons
x = 10
print(x > 5)             # True
print(x == 3)            # False
print(type(x > 5))       # <class 'bool'> — comparisons ARE booleans

# You can store comparison results in variables
is_adult = x > 18
print(is_adult)           # False
print(f"Is adult: {is_adult}")
🚨 true and false (lowercase) will crash your program

True and False are Python keywords — they must be capitalised exactly. true (lowercase) is just an undefined variable name and causes a NameError.

This is one of the most common beginner errors. Every time. Capital T. Capital F. Write it like that, always.

02 Booleans behave like numbers
✓
Mark done

Here's something that surprises most beginners: in Python, True is literally equal to 1 and False is literally equal to 0. This is because Python's bool type is a subclass of int. You can do maths with booleans.

🟡 Booleans as numbers — this is real Python, not a trick
# True == 1, False == 0
print(True == 1)     # True
print(False == 0)    # True
print(True > False)  # True — 1 > 0

# Arithmetic with booleans
print(True + True)   # 2
print(True + 5)      # 6
print(False * 100)   # 0

# PRACTICAL USE: Count how many conditions are True
# Imagine checking eligibility for a loan
has_id = True
has_income = True
has_good_credit = False
is_kenyan_resident = True

# sum() treats True as 1 and False as 0 — genius!
conditions_met = has_id + has_income + has_good_credit + is_kenyan_resident
print(f"Met {conditions_met} out of 4 conditions")  # Met 3 out of 4

# Or with a list and sum()
checks = [has_id, has_income, has_good_credit, is_kenyan_resident]
print(f"Conditions passed: {sum(checks)}/4")
💡 Why would you ever use this?

The bool-as-number behaviour appears constantly in real code. Common uses include: counting how many items in a list satisfy a condition, summing up flagged rows in data, and conditional calculations where you want to add something only if a condition is True.

Example: discount = 0.1 * is_member — if is_member is True (1), discount is 10%. If False (0), discount is 0%. One clean line instead of an if/else block.

03 Comparison operators
✓
Mark done

Comparison operators compare two values and always return a boolean — either True or False. These are the building blocks of all decision-making in Python.

OperatorMeaningExampleResult
==Equal to5 == 5True
!=Not equal to5 != 3True
>Greater than10 > 3True
<Less than2 < 5True
>=Greater than or equal4 >= 4True
<=Less than or equal2 <= 1False
🟡 Comparison operators — predict each result before running
# Basic number comparisons
print(10 == 10)    # True
print(10 == 10.0)  # True — int and float can be equal
print(7 != 3)     # True
print(7 != 7)     # False
print(5 > 5)      # False — strictly greater, NOT equal
print(5 >= 5)     # True  — greater OR equal

# String comparisons — alphabetical (lexicographic) order
print("apple" == "apple")   # True
print("apple" == "Apple")   # False — case sensitive!
print("b" > "a")            # True  — 'b' comes after 'a'
print("banana" < "cherry")  # True  — 'b' before 'c'

# Python allows CHAINED comparisons — read naturally!
age = 22
print(18 <= age < 65)    # True — works exactly like maths: 18 ≤ age < 65
print(0 < age < 18)      # False — age is NOT between 0 and 18

score = 85
is_grade_b = 80 <= score < 90
print(f"Grade B? {is_grade_b}")   # True
🚨 = is assignment. == is comparison. They are NOT the same.

age = 25 — stores the value 25 in the variable age.

age == 25 — asks "is age equal to 25?" Returns True or False.

Using = instead of == in a comparison is one of the most common bugs beginners write. Python will usually give you a SyntaxError or produce completely wrong logic silently. Always double-check which one you're using.

04 Logical operators: and, or, not
✓
Mark done

Logical operators let you combine multiple boolean expressions into one. They're how you build real conditions: "must be over 18 AND have a valid ID", "must be student OR senior citizen".

and — both must be True

🟡 The 'and' operator
# 'and' returns True ONLY when BOTH conditions are True
# If either is False, the whole expression is False

print(True and True)    # True  — both True
print(True and False)   # False — one is False
print(False and True)   # False — one is False
print(False and False)  # False — both False

# Real example: can this person drive?
# Must be 18+ AND have a valid licence
age = 20
has_licence = True

can_drive = age >= 18 and has_licence
print(f"Can drive: {can_drive}")  # Can drive: True

# What if they are underage?
age = 16
can_drive = age >= 18 and has_licence
print(f"Can drive: {can_drive}")  # Can drive: False

# Real example: validate a password
password = "MyPass123"
is_long_enough = len(password) >= 8
has_number = any(c.isdigit() for c in password)
is_valid_password = is_long_enough and has_number
print(f"Password valid: {is_valid_password}")  # True

or — at least one must be True

🟡 The 'or' operator
# 'or' returns True when AT LEAST ONE condition is True
# Only False when BOTH are False

print(True or True)    # True
print(True or False)   # True
print(False or True)   # True
print(False or False)  # False — only case where or returns False

# Real example: discount eligibility
# Student OR senior citizen gets a discount
is_student = True
is_senior = False

gets_discount = is_student or is_senior
print(f"Gets discount: {gets_discount}")  # True — student qualifies

# Real example: emergency alert
# Send alert if temperature is too high OR too low
temperature = 42.5
too_hot = temperature > 38
too_cold = temperature < 15

send_alert = too_hot or too_cold
print(f"Send alert: {send_alert}")  # True — it's 42.5, too hot

not — flip the boolean

🟡 The 'not' operator
# 'not' reverses the boolean — True becomes False, False becomes True
print(not True)         # False
print(not False)        # True
print(not (5 > 3))      # False — 5>3 is True, not True = False

# Real example: access control
is_banned = False
can_access = not is_banned
print(f"Can access: {can_access}")   # True — not banned = can access

# Another example: check if a list is empty
my_list = []
print(not my_list)          # True — empty list is falsy, not empty = True

shopping_cart = ["milk", "bread"]
print(not shopping_cart)    # False — not empty

# Combining all three: complex conditions
age = 25
is_member = True
has_debt = False

# Eligible if: adult, member, AND no outstanding debt
eligible = age >= 18 and is_member and not has_debt
print(f"Eligible: {eligible}")  # True

05 Truthy and falsy values
✓
Mark done

Here's something Python does that surprises almost every beginner: values that are not booleans can still be evaluated as true or false in a boolean context. This is called truthiness. Some values behave like True, others like False.

💡 What makes something "falsy" in Python?

Python's rule is: empty things and zero things are falsy. Everything else is truthy. Once you understand that one rule, you can predict the behaviour of any value.

ValueTypeTruthy or Falsy?Why
0intFalsyZero = nothing
0.0floatFalsyZero = nothing
""strFalsyEmpty string
[]listFalsyEmpty list
{}dictFalsyEmpty dict
NoneNoneTypeFalsyThe "nothing" value
FalseboolFalsyLiterally False
1, -5, 3.14int/floatTruthyNon-zero numbers
"hello", "0"strTruthyNon-empty strings
[1, 2], [False]listTruthyNon-empty (even if contents are falsy)
TrueboolTruthyLiterally True
🟡 Truthiness in practice
# bool() converts any value to its boolean equivalent
print(bool(0))       # False
print(bool(1))       # True
print(bool(""))      # False
print(bool("Hi"))   # True
print(bool([]))      # False
print(bool([0]))    # True — list has one item, even if that item is 0
print(bool(None))   # False

# Truthy/falsy is used everywhere. You can skip the == True check!
name = "Kofi"

# VERBOSE — works but unnecessary
if name != "":
    print("Name is set")

# PYTHONIC — same thing, cleaner
if name:
    print("Name is set")   # This runs because "Kofi" is truthy

# Check if a list has items
results = []
if not results:
    print("No results found")   # Runs because [] is falsy

results = ["item1", "item2"]
if results:
    print(f"Found {len(results)} results")   # Runs because list is non-empty
Pythonic style: In Python, it's considered cleaner to write if name: instead of if name != "":, and if not items: instead of if len(items) == 0:. Python developers rely on truthiness constantly. Learn it now and your code will look professional immediately.

06 Short-circuit evaluation
✓
Mark done

Python is lazy about evaluating logical expressions — in the best way. It stops as soon as it knows the answer. This is called short-circuit evaluation and it has practical implications you need to understand.

🟡 How short-circuiting works
# With 'and': if the FIRST condition is False, Python skips the second
# It already knows the result can't be True
print(False and 1/0)   # False — 1/0 would crash, but it's never evaluated!

# With 'or': if the FIRST condition is True, Python skips the second
# It already knows the result must be True
print(True or 1/0)    # True — 1/0 is never evaluated

# PRACTICAL USE 1: Safe division (avoid ZeroDivisionError)
denominator = 0
# Check denominator is non-zero FIRST — if False, division never runs
result = denominator != 0 and 100 / denominator
print(result)  # False — safe, no error

denominator = 4
result = denominator != 0 and 100 / denominator
print(result)  # 25.0

# PRACTICAL USE 2: Default values with 'or'
# If the first value is falsy, 'or' returns the second value
user_name = ""
display_name = user_name or "Guest"
print(display_name)  # Guest — user_name is empty (falsy), so or returns "Guest"

user_name = "Amara"
display_name = user_name or "Guest"
print(display_name)  # Amara — user_name is truthy, or returns it directly
💡 and and or don't just return True/False — they return values

This is a deeper nuance: Python's and and or return one of the actual operands, not necessarily a bool.

  • and returns the first falsy operand, or the last value if all are truthy.
  • or returns the first truthy operand, or the last value if all are falsy.

This is why user_name or "Guest" works — if user_name is empty (falsy), or returns "Guest". This pattern is very common in Python for providing default values.

You now understand the entire boolean system: how to create True/False values, how comparisons produce them, how to combine them with and/or/not, what makes any value truthy or falsy, and how Python evaluates logical expressions efficiently. This is the foundation of every if statement, loop condition, and filter operation you'll ever write.

07 Mini challenge

🎯 Challenge — Access Control System

Build a multi-condition access control checker without using if statements — just boolean expressions.

Given these variables:
age = 21, is_member = True, has_paid = False, is_staff = False, attempts = 3

1. can_enter_basic: age is 18+
2. can_enter_paid: is_member AND has_paid AND age is 18+
3. can_enter_vip: is_staff OR (is_member AND has_paid AND age is 21+)
4. is_locked_out: attempts >= 5
5. has_default_name: use user_name = "" and the or trick to set display name to "Visitor"
6. Print each result with a descriptive label

🟡 Solution
age = 21
is_member = True
has_paid = False
is_staff = False
attempts = 3
user_name = ""

can_enter_basic = age >= 18
can_enter_paid  = is_member and has_paid and age >= 18
can_enter_vip   = is_staff or (is_member and has_paid and age >= 21)
is_locked_out   = attempts >= 5
display_name    = user_name or "Visitor"

print(f"Display name:        {display_name}")
print(f"Can enter (basic):   {can_enter_basic}")
print(f"Can enter (paid):    {can_enter_paid}")
print(f"Can enter (VIP):     {can_enter_vip}")
print(f"Locked out:          {is_locked_out}")

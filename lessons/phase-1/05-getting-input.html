01 input() — how it works
✓
Mark done

The input() function pauses your program and waits for the user to type something and press Enter. Whatever they type is returned as a value you can store in a variable.

🔁 Like a form on a website — but in the terminal

When you fill out a form online, the website stops and waits for you. You type, you hit submit, and the website receives your answer and acts on it.

input() is exactly that — but in your terminal. Your program reaches that line, stops, puts a prompt on the screen, and waits. Once you press Enter, the program continues with whatever you typed.

🟡 Basic input() — run this in your terminal or Jupyter
# input() shows a prompt and returns whatever the user types
# The string inside () is what gets displayed to the user

name = input("What is your name? ")

# The program pauses here until Enter is pressed
# Whatever the user typed is now stored in 'name'

print(f"Hello, {name}!")
print(f"Your name has {len(name)} characters.")
🖥️ What it looks like when running
What is your name? Amara
Hello, Amara!
Your name has 5 characters.
💡 The prompt string is optional — but always include it

input() can be called with no argument: user_input = input(). The program will still pause and wait, but the user will see a blank terminal with no explanation — they won't know what to type.

Always provide a clear, helpful prompt. Tell the user exactly what you want. And add a space or colon at the end of your prompt string so the cursor appears after it, not right next to the last character.

✅ input("Enter your age: ") → cursor appears after the space
❌ input("Enter your age:") → cursor jammed against the colon

Multiple inputs

🟡 Collecting several inputs in sequence
# Just call input() multiple times — each one pauses the program
first_name = input("First name: ")
last_name  = input("Last name: ")
city       = input("City: ")

# Now use everything collected
print(f"\n--- Profile ---")
print(f"Name: {first_name} {last_name}")
print(f"City: {city}")

02 The critical rule: everything is a string
✓
Mark done

This is the single most important fact about input(), and it trips up every beginner at least once:

input() ALWAYS returns a string. No exceptions. Even if the user types a number.
🟡 Proving that input() returns a string — observe the types
# Imagine the user types "25" when prompted
# (For this example we'll simulate it with a variable)

raw_age = "25"   # This is what input() gives you — a STRING

print(type(raw_age))        # <class 'str'> — NOT int
print(raw_age + 5)          # CRASH: TypeError! Can't add str and int
Error output (this is what you'll see)
TypeError: can only concatenate str (not "int") to str
🚨 The classic beginner bug — every single time

You ask for a number. The user types 25. You try to add 1 to it. Python crashes with a TypeError. You stare at it confused because it looks like a number. It isn't. It's the string "25".

You must convert the string to an int or float before doing any maths. This conversion step is not optional. It's not something you do sometimes. You do it every time you want a number from the user.

03 Converting input to the right type
✓
Mark done

The fix is simple: wrap input() with the appropriate conversion function. There are two patterns — wrapping directly or storing then converting.

🟡 Pattern 1: Wrap input() directly
# Convert on the same line as input()
# int() wraps input() — converts the string to an integer immediately
age = int(input("Enter your age: "))

# Now age is already an integer — maths works
print(f"In 10 years you'll be {age + 10}")
print(type(age))   # <class 'int'>

# For decimals — use float()
price = float(input("Enter price: "))
print(f"Price with VAT: {price * 1.16:.2f}")
🟡 Pattern 2: Store first, convert after (better for validation)
# Store the raw string first
raw_age = input("Enter your age: ")

# Then validate BEFORE converting (we'll cover this properly in s4)
# For now, just convert
age = int(raw_age)

print(f"Age: {age}")
print(f"Type: {type(age)}")   # <class 'int'>

# Get two numbers from the user and show their sum, difference, product
print("=== Simple Calculator ===")

num1 = float(input("Enter first number: "))
num2 = float(input("Enter second number: "))

print(f"\nResults:")
print(f"  {num1} + {num2} = {num1 + num2}")

if num2 != 0:
    print(f"  {num1} ÷ {num2} = {num1 / num2:.4f}")
else:
    print("  Division not possible — second number is zero")

04 Validating input before using it
✓
Mark done

The problem with wrapping int(input()) directly is that if the user types something that isn't a number — like "hello" or just hits Enter — your program crashes with a ValueError. In real programs, you must never trust user input blindly.

Method 1: isdigit() check before converting

isdigit() checks whether every character in a string is a digit. It's quick, clean, and works well for simple whole-number validation.

🟡 isdigit() — the simple validation approach
# isdigit() returns True if the string contains ONLY digit characters
print("25".isdigit())     # True
print("25.5".isdigit())   # False — decimal point is not a digit
print("-5".isdigit())     # False — minus sign is not a digit
print("abc".isdigit())    # False
print("".isdigit())       # False — empty string

# Safe age input using isdigit()
raw = input("Enter your age: ")

if raw.isdigit():
    age = int(raw)
    print(f"Age accepted: {age}")
else:
    print("That doesn't look like a valid age. Please enter a whole number.")

# Validate a quantity input (must be positive whole number)
raw_qty = input("How many items? ")

if raw_qty.isdigit() and int(raw_qty) > 0:
    qty = int(raw_qty)
    print(f"Adding {qty} items to cart")
else:
    print("Please enter a positive whole number")
Limitation of isdigit(): It only handles whole positive numbers. It rejects -5, 3.14, and 1,000. For floats or negative numbers, you need the try/except pattern from the next section.

Method 2: strip() + lower() for text input

🟡 Cleaning text input before using it
# Users often type with different cases or accidental spaces
# Always clean text input before comparing it

answer = input("Do you want to continue? (yes/no): ")

# Clean it: remove spaces from both ends, convert to lowercase
clean_answer = answer.strip().lower()

# Now compare safely — works whether user typed YES, Yes, yes, " yes ", etc.
if clean_answer == "yes":
    print("Continuing...")
elif clean_answer == "no":
    print("Stopping.")
else:
    print(f"I didn't understand '{clean_answer}'. Please type yes or no.")

# Shorter version — on one line
wants_receipt = input("Print receipt? ").strip().lower() == "yes"
print(f"Print receipt: {wants_receipt}")  # True or False

05 Safe input with try/except
✓
Mark done

For robust number conversion — especially floats and negatives — the cleanest approach is a try/except block. You try to convert the input, and if it fails, you catch the error and handle it gracefully instead of crashing.

💡 Error handling is not just for advanced programmers

Beginners often think try/except is advanced. It isn't. It's necessary. Any program that takes user input will eventually receive bad input. A program that crashes on bad input is a broken program. try/except is how you fix that.

You don't need to understand the full error handling system yet (that's Phase 2). Just learn this one pattern: wrap any conversion in a try/except ValueError.

🟡 The safe input pattern — use this whenever you convert input
# The pattern: try to convert, catch the error if it fails

raw = input("Enter a number: ")

try:
    # Try to convert — this runs if input is a valid number
    number = float(raw)
    print(f"You entered: {number}")
    print(f"Double: {number * 2}")

except ValueError:
    # This runs ONLY if float(raw) failed — e.g. user typed "hello"
    print(f"'{raw}' is not a valid number. Please try again.")

# The program continues normally after try/except — no crash!
print("Program finished.")

Combining validation with a loop

For a truly robust program, keep asking until you get valid input:

🟡 Keep asking until the user gives valid input
# while True loops forever. We break out only when input is valid.
# (You'll learn loops fully in Phase 2 — this is a preview)

while True:
    raw = input("Enter your age (a whole number): ")
    try:
        age = int(raw)
        if age < 0 or age > 120:
            print("Age must be between 0 and 120. Try again.")
            continue   # go back to the top of the loop
        break          # valid! exit the loop
    except ValueError:
        print("That's not a valid number. Try again.")

print(f"Age confirmed: {age}")
This is the gold standard pattern for user input. In real applications — web forms, CLIs, APIs — you always validate, always handle errors, always give the user a clear message. Even if your first scripts are simple, build the habit now.

06 Building an interactive script
✓
Mark done

Let's put everything from Phase 1 together — variables, strings, numbers, booleans, and input — into one real, working program.

🟡 Grade Calculator — a complete interactive script
# ============================================================
#  GRADE CALCULATOR
#  Collects student marks, calculates average, assigns grade
# ============================================================

print("=" * 40)
print("       STUDENT GRADE CALCULATOR")
print("=" * 40)

# --- Collect student information ---
student_name = input("\nStudent name: ").strip().title()
course       = input("Course: ").strip()

# --- Collect marks with validation ---
subjects = ["Maths", "English", "Science"]
marks = []

print("\nEnter marks (0–100):")

for subject in subjects:
    while True:
        raw = input(f"  {subject}: ")
        try:
            mark = float(raw)
            if 0 <= mark <= 100:
                marks.append(mark)
                break
            else:
                print("    Mark must be between 0 and 100.")
        except ValueError:
            print("    Please enter a number.")

# --- Calculate results ---
average = sum(marks) / len(marks)
highest = max(marks)
lowest  = min(marks)

# Assign grade based on average
if average >= 90:
    grade = "A"
elif average >= 80:
    grade = "B"
elif average >= 70:
    grade = "C"
elif average >= 60:
    grade = "D"
else:
    grade = "F"

passed = average >= 50

# --- Print report ---
print(f"\n{'='*40}")
print(f"  REPORT CARD")
print(f"{'='*40}")
print(f"  Student: {student_name}")
print(f"  Course:  {course}")
print(f"{'─'*40}")
for i, subject in enumerate(subjects):
    print(f"  {subject:12}   {marks[i]:>6.1f}")
print(f"{'─'*40}")
print(f"  Average:      {average:>6.1f}%")
print(f"  Highest:      {highest:>6.1f}%")
print(f"  Lowest:       {lowest:>6.1f}%")
print(f"  Grade:             {grade}")
print(f"  Passed:        {'Yes ✓' if passed else 'No ✗'}")
print(f"{'='*40}")

🎯 Challenge — Shopping Cart Calculator

Build a simple shopping cart that takes 3 items from the user, calculates the total, applies a discount if one is entered, and prints a receipt.

1. Ask for item name and price 3 times using a loop (hint: for i in range(3):)
2. Validate each price — must be a positive number using try/except
3. After items, ask for an optional discount code. If they enter SAVE10, apply 10% discount
4. Calculate subtotal, discount amount, and final total
5. Print a formatted receipt with all items, subtotal, discount (if any), and total
6. Include the item count in the receipt

🟡 Solution
print("=== Shopping Cart ===")
items = []

for i in range(1, 4):
    name = input(f"Item {i} name: ").strip()
    while True:
        try:
            price = float(input(f"Item {i} price (KES): "))
            if price < 0:
                print("Price can't be negative.")
            else:
                break
        except ValueError:
            print("Please enter a valid number.")
    items.append((name, price))

code = input("\nDiscount code (or Enter to skip): ").strip().upper()
discount_pct = 0.10 if code == "SAVE10" else 0

subtotal = sum(p for _, p in items)
discount = subtotal * discount_pct
total = subtotal - discount

print("\n" + "=" * 35)
print("         RECEIPT")
print("=" * 35)
for name, price in items:
    print(f"  {name:18} KES {price:>7,.2f}")
print("─" * 35)
print(f"  Subtotal ({len(items)} items) KES {subtotal:>7,.2f}")
if discount > 0:
    print(f"  Discount (SAVE10)    KES -{discount:>6,.2f}")
print(f"  TOTAL               KES {total:>7,.2f}")
print("=" * 35)
print("  Thank you for shopping!")

Task 01 — Easy

Write a program that asks for someone's name and age, then prints: "Hello [Name]! You were born in approximately [year]." Calculate the birth year. Clean the name input with .strip().title().

Task 02 — Easy

Ask the user to enter a word. Print: the word in all caps, the word reversed, its length, and whether it's a palindrome (reads the same forwards and backwards). Use only string methods and slicing — no imports needed.

Task 03 — Medium

BMI calculator. Get weight (kg) and height (m) from the user using try/except float(). Calculate BMI = weight / height². Print the BMI rounded to 1 decimal place and the category: Underweight (<18.5), Normal (18.5–24.9), Overweight (25–29.9), Obese (30+).

Task 04 — Medium

Temperature converter. Ask the user to enter a temperature AND the unit (C or F). Convert appropriately. Validate: unit must be C or F (case-insensitive), temperature must be a valid number. Print the converted result with 2 decimal places and the unit.

Task 05 — Challenge

Tip calculator. Get: restaurant bill amount, number of people splitting it, and service rating (1=poor, 2=ok, 3=great). Calculate tip rate: 0% for poor, 10% for ok, 15% for great. Print: tip amount, total bill, and each person's share — all formatted to 2 decimal places with KES prefix. Validate all inputs.

Task 06 — Phase 1 Capstone

Build a personal finance tracker. Collect: monthly income, then expenses for rent, food, transport, and utilities (4 inputs). Calculate total expenses, savings (income - expenses), savings rate (%), and whether expenses exceed income. Print a formatted monthly summary. Validate all inputs. Handle the case where income is 0 (no division by zero).

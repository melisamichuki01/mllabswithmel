1 What is a Variable?
✓
done

Before we look at any code, let's understand what a variable actually is — because the word sounds more complicated than the idea.

🔄 In plain life terms...

Imagine you're cooking ugali. You have different containers in your kitchen — one for unga, one for salt, one for water. Each container has a label, and inside it is some specific thing.

A variable in Python works exactly the same way. The label is the variable name. The contents is the value you're storing. When you say name = "Wanjiku", you're creating a container called name and putting the value "Wanjiku" inside it. From that point on, every time you say name in your code, Python goes and fetches "Wanjiku" for you.

Here's how you create a variable in Python. The pattern is always the same:

🔁 Python Script
# The pattern: variable_name = value
# The = sign means "store this value here"

name = "Wanjiku"       # A container called "name" holding the text "Wanjiku"
age = 24              # A container called "age" holding the number 24
height = 1.65         # A container called "height" holding a decimal number
is_student = True    # A container called "is_student" holding True or False
🚨 Wait — the = sign doesn't mean "equals" here!

This is one of the most confusing things for beginners. In Python, = is the assignment operator — it means "put the thing on the right into the container on the left."

It is not asking "are these two things equal?" That's a completely different thing (== — two equals signs). We'll get to that in Lesson 1.4.

So when you see age = 24, read it in your head as: "age gets the value 24" — not "age equals 24."

Each variable has a name, a type, and a value. Python tracks all three automatically.

Notice that we never had to tell Python what kind of container to use. Python looked at the value and figured it out on its own. That's called dynamic typing — it's one of the things that makes Python beginner-friendly.

💡 What does "dynamic typing" actually mean?

In some programming languages (like Java or C++), you have to declare the type of a variable before you use it. You'd write something like: String name = "Wanjiku"; — specifying upfront that this container holds text only.

Python doesn't need that. You just write name = "Wanjiku" and Python says "I see quotes around this, so this must be text. Got it." Python reads the value and assigns the type automatically.

This means Python is flexible — but it also means you need to be aware of what type your variables are, because Python will behave differently depending on the type. We'll see exactly why that matters later in this lesson.

2 The 4 Core Data Types
✓
done

Python knows about many different kinds of data. But at this stage, there are four that you'll use constantly. Learn these four and you can handle the vast majority of beginner problems.

TypeFull NameWhat it storesExample
str String Text — anything in quotes "Nairobi", 'hello'
int Integer Whole numbers, no decimal 5, -3, 1000
float Float Decimal numbers 3.14, 99.9, -0.5
bool Boolean Only True or False True, False

🏷️ Strings (str)

A string is any piece of text. The defining feature is the quotes around it. You can use single quotes or double quotes — Python treats them the same way.

🔁 Python Script
# All of these are strings — notice the quotes
city = "Nairobi"
greeting = 'Mambo vipi!'
sentence = "She scored 98% in the exam"
empty_string = ""        # An empty string — still a string!

# Triple quotes for multi-line text
message = """This is a message
that spans multiple
lines."""
🚨 "42" is NOT the same as 42 — this trips everyone up

Look at these two things side by side:

  • "42" — this is a string. It's text that happens to look like a number. Python sees the quotes and treats it like letters.
  • 42 — this is an integer. It's an actual number. You can do maths with it.

Why does this matter? Because if you try to add "42" + 8, Python will throw an error. You can't do maths with text. We'll learn how to convert between types later in this lesson.

🔢 Integers (int)

An integer is a whole number — positive, negative, or zero. No decimal point.

🔁 Python Script
students_in_class = 32
temperature_today = 28       # Degrees Celsius in Nairobi
bank_balance = -500           # Negative numbers work too
items_in_basket = 0           # Zero is a valid integer

# Pro tip: use underscores in large numbers for readability
population_nairobi = 4_500_000   # Python ignores the underscores

🔶 Floats (float)

A float is a number with a decimal point. Use floats when precision matters: prices, measurements, scientific values, percentages, averages.

🔁 Python Script
price_of_milk = 65.50         # Kenyan shillings — decimal needed
gpa = 3.7
weight_kg = 72.4
pi = 3.14159

# Watch this! Even if there's nothing meaningful after the decimal, it's still a float
score = 95.0   # This is a float, NOT an integer
💡 When to use int vs float?

Use int when counting things that can't be split — number of students, number of M-Pesa transactions, number of items in a list.

Use float when measuring things that can have fractional values — prices, weights, heights, percentages, test averages.

Here's something slightly surprising: if you divide two integers in Python, you might get a float back. 9 / 2 gives you 4.5 — not 4. Python is being accurate by preserving the decimal.

💡 Booleans (bool)

A boolean has only two possible values: True or False. That's it. Nothing else. The simplest data type in Python, but incredibly powerful — it drives all the decision-making in your programs.

🔁 Python Script
is_logged_in = True
has_paid_fees = False
exam_passed = True
is_raining = False

# IMPORTANT: True and False must have capital first letters
# Writing "true" or "false" (lowercase) will cause a NameError!
🔄 Think of booleans like a light switch

A light switch has exactly two states: ON or OFF. There's no "maybe" position, no 30% on, no 80% off. It's binary — one or the other.

That's exactly what a boolean is. True is the switch being ON. False is the switch being OFF. When Python is making decisions — "should I show this message?" or "should I let this user log in?" — it's always asking a boolean question, and the answer is always True or False.

⚠️

Capital letters are not optional for booleans. True and False must start with capital letters. Write true or false and Python throws a NameError — it thinks you're trying to use a variable called true that doesn't exist.

⚡ Quick Check — Spot the Type

For each value below, what type is it — str, int, float, or bool?

  • "Kisumu"
  • 100
  • False
  • 3.14
  • "True"
  • 0
  • -7.5

"Kisumu" → str — it has quotes

100 → int — whole number, no quotes

False → bool — capital F, no quotes

3.14 → float — has a decimal point

"True" → str — it has quotes! The quotes override everything. This is NOT a boolean.

0 → int — still a number, just zero

-7.5 → float — negative decimal

3 Naming Rules
✓
done

You can name a variable almost anything — but there are a few rules Python enforces, and some conventions that experienced Python developers follow. Learn both.

✅ These are allowed

  • Start with a letter or underscore: name, _hidden
  • Use letters, numbers, underscores: student_2, total_score
  • Any length works

❌ These will cause errors

  • Start with a number: 2students
  • Contain spaces: my name
  • Use special characters: price@shop
  • Use Python keywords: if, for, True
🔁 Valid vs invalid variable names
# All of these are valid Python variable names
student_name = "Aisha"
total_score2 = 98         # Number at the END is fine
x = 10                    # Single letters are valid — but not very descriptive

# These would cause errors — don't try them
# 2student = "Brian"       # Can't start with a number
# my name = "Mel"          # Can't have spaces
# price@mpesa = 500        # Can't use @ symbol

Python convention: use snake_case

Python programmers follow a style called snake_case for variable names — all lowercase letters, with underscores between words. It's not enforced by Python itself, but you'll see it in every Python codebase in the world. Follow it from day one.

🔁 Convention: snake_case
# Correct Python convention (snake_case)
student_name = "Wanjiru"
total_marks = 87
is_enrolled = True
number_of_courses = 4

# These work but go against Python convention
# studentName = "Wanjiru"   # camelCase — Java style, not Python
# StudentName = "Wanjiru"   # PascalCase — used for class names, not variables
💡

Python is case-sensitive. name, Name, and NAME are three completely different variables. If you create student_name on line 1 and try to use Student_name on line 5, Python throws a NameError — because as far as Python is concerned, that second variable doesn't exist.

Make your names descriptive

One of the most important habits you can build early: give your variables names that explain what they hold.

🔁 Bad names vs good names
# What does any of this mean?
a = 28
b = 5
c = 140

# Now it's obvious
temperature_celsius = 28
number_of_items = 5
price_in_shillings = 140

4 Reassigning Variables
✓
done

Variables aren't permanent. You can change what they hold at any point by simply assigning a new value. The old value is gone — replaced by the new one.

🔁 Python Script
mood = "stressed"
print(mood)        # Output: stressed

mood = "excited"    # Reassigned — old value is gone
print(mood)        # Output: excited

mood = "tired"      # Reassign again — perfectly fine
print(mood)        # Output: tired
🔄 Here's the everyday version of that

Think of a whiteboard with your name written on it. You can erase what's on it and write something new. The whiteboard is still the same whiteboard — but the content has changed.

That's what reassigning a variable does. The container (the whiteboard) stays. The value (what's written on it) gets replaced.

Python also lets you change the type when reassigning

Because Python is dynamically typed, you can assign a completely different type of value to a variable you already created. Python just updates the type automatically.

🔁 Python Script
score = 75          # score is currently an integer
print(type(score))  # Output: <class 'int'>

score = "Merit"      # Now score is a string — Python allows this
print(type(score))  # Output: <class 'str'>

Multiple assignment shortcuts

🔁 Python Script
# Assign the same value to multiple variables at once
x = y = z = 0
print(x, y, z)    # Output: 0 0 0

# Assign different values to multiple variables in one line
name, age, city = "Kamau", 30, "Mombasa"
print(name)    # Output: Kamau
print(age)     # Output: 30
print(city)    # Output: Mombasa

5 Checking the Type of a Variable
✓
done

Python gives you a built-in function called type() that tells you exactly what type a variable is. This is extremely useful when debugging — when something's going wrong and you're not sure why, checking the type often solves the mystery.

🔁 Python Script
name = "Otieno"
age = 22
gpa = 3.8
is_enrolled = True

print(type(name))         # Output: <class 'str'>
print(type(age))          # Output: <class 'int'>
print(type(gpa))          # Output: <class 'float'>
print(type(is_enrolled))  # Output: <class 'bool'>

# You can also use type() on a value directly
print(type(42))       # <class 'int'>
print(type("42"))     # <class 'str'> — the quotes make it text!
⚡ Mini Challenge — Use type() to investigate

Before running this code, predict what type() will return for each variable. Then run it and check your predictions.

🔁 Try this
a = 100
b = 100.0
c = "100"
d = True
e = False + 5   # What happens when you add False to a number?

print(type(a), a)
print(type(b), b)
print(type(c), c)
print(type(d), d)
print(type(e), e)

a → int, value: 100

b → float, value: 100.0 (the .0 makes it a float)

c → str, value: 100 displayed as text

d → bool, value: True

e → int, value: 5 — in Python, False = 0 mathematically, so 0 + 5 = 5. This is a quirk of booleans we'll explore in Lesson 1.4!

6 Type Conversion
✓
done

Sometimes you have a value in one type but you need it in another. When a user types their age into your program, Python receives it as a string — text — not a number. If you want to do maths with it, you need to convert it. This process is called type conversion or casting.

🔄 Real world version

Imagine someone hands you their age on a piece of paper. It says "24". That paper is text — you can read it, but you can't add 5 years to a piece of paper. You need to take the number off the paper and put it into your calculator first.

That's what type conversion does. It takes data that exists in one form and transforms it into a form your program can work with.

Python gives you four main conversion functions:

→ str()
Converts to text
str(42) → "42"
→ int()
Converts to whole number
int("25") → 25
→ float()
Converts to decimal
float("3.14") → 3.14
→ bool()
Converts to True/False
bool(0) → False
🔁 Type conversion in action
# Converting TO string
age = 24
age_as_text = str(age)         # 24 (int) → "24" (str)
print(type(age_as_text))        # Output: <class 'str'>

# Converting TO integer
user_input = "35"              # Imagine this came from a user typing
actual_age = int(user_input)    # "35" (str) → 35 (int)
print(actual_age + 5)           # Output: 40 — now we can do maths!

# Converting TO float
price_text = "299.99"
price = float(price_text)       # "299.99" (str) → 299.99 (float)
print(price * 2)                # Output: 599.98

# int → float and back
x = 10
print(float(x))                 # Output: 10.0 — adds the decimal

y = 7.9
print(int(y))                   # Output: 7 — chops the decimal (does NOT round!)
🚨 int() chops, it doesn't round — pay attention to this one

When you convert a float to an int using int(), Python removes everything after the decimal point. It does not round.

int(7.9) gives you 7, not 8. int(3.1) gives you 3.

This is called truncation. If you want proper rounding, use round() instead: round(7.9) gives 8.

When conversion fails

You can only convert values that make sense. Python can't convert the word "hello" into a number. If you try, you'll get a ValueError.

🔁 Conversion errors
# This works — "42" looks like a number
print(int("42"))         # Output: 42

# This fails — "hello" has no numeric equivalent
# print(int("hello"))     # ValueError!

# This also fails — "3.14" has a decimal, int() can't handle that directly
# print(int("3.14"))      # ValueError!

# But you can go through float first
print(int(float("3.14")))  # Output: 3 — convert to float first, then to int
⚡ Mini Challenge — Fix the broken code

The code below is trying to calculate a student's total score. But it will throw an error. Can you spot why, and fix it?

🔁 Broken code — find the bug
score_one = "45"      # Score from the first test
score_two = "52"      # Score from the second test

total = score_one + score_two
print("Total score:", total)

The scores are stored as strings (they have quotes). Adding two strings doesn't add their values — it joins them. So "45" + "52" gives "4552", not 97.

Fix: Convert both to integers first.

score_one = int("45")
score_two = int("52")
total = score_one + score_two
print("Total score:", total)  # Output: Total score: 97

7 print() Mastery
✓
done

You've been using print() from the start. Let's go deeper — because knowing your print options makes debugging easier and your output much cleaner.

Method 1: Basic print

🔁 Python Script
name = "Amara"
print(name)       # Output: Amara
print("Hello!")   # Output: Hello!
print(42)         # Output: 42

Method 2: Multiple values separated by commas

🔁 Python Script
name = "Amara"
age = 26

# Separate values with commas — Python adds a space between them automatically
print("Name:", name, "Age:", age)
# Output: Name: Amara Age: 26

Method 3: String concatenation

🔁 Python Script
name = "Amara"
age = 26

# Join strings with + — all values must be strings
# Numbers must be wrapped in str() first
print("My name is " + name + " and I am " + str(age) + " years old.")
# Output: My name is Amara and I am 26 years old.

Method 4: f-strings ⭐ (The recommended way)

f-strings are the modern Python way to build strings with variables. Put an f before the opening quote, then drop your variables into curly braces {}. No type conversion needed, easy to read, you can do calculations inline.

🔁 f-strings
name = "Amara"
age = 26
gpa = 3.75

# f before the quote, {} around variables
print(f"My name is {name} and I am {age} years old.")
# Output: My name is Amara and I am 26 years old.

# You can do calculations inside the {}
print(f"In 5 years, {name} will be {age + 5} years old.")
# Output: In 5 years, Amara will be 31 years old.

# Format numbers — control decimal places
print(f"GPA: {gpa:.1f}")    # Output: GPA: 3.8 (1 decimal place)
print(f"GPA: {gpa:.2f}")    # Output: GPA: 3.75 (2 decimal places)
💡 Why f-strings are the recommended way

Compared to concatenation with +:

  • No need to wrap numbers in str() — f-strings handle conversion for you
  • Much easier to read — you can see exactly what the output will look like
  • You can do maths, call functions, and format numbers right inside the {}

The f stands for "formatted string literal." They were introduced in Python 3.6 and are now the standard. If you ever see old code using %s or .format(), those are older approaches that do the same thing. Stick with f-strings.

Useful print() extras

🔁 print() options
# By default, print() adds a newline at the end
print("Line 1")
print("Line 2")
# Output:
# Line 1
# Line 2

# Use end="" to stay on the same line
print("Hello", end=" ")
print("World")
# Output: Hello World

# Use sep="" to change the separator between multiple values
print("Mon", "Tue", "Wed", sep=" | ")
# Output: Mon | Tue | Wed

# Print a blank line
print()
# Output: (blank line)

🔗 How it all fits together

Everything you learned today is foundational — every Python program you'll ever write, from a simple script to a machine learning model, uses variables and data types. Quick recap:

  • Variables are named containers that store values. The pattern is always name = value.
  • Python is dynamically typed — it figures out the type automatically from the value you assign.
  • The 4 core types: str (text), int (whole number), float (decimal), bool (True/False).
  • Naming rules: snake_case, no spaces, no special characters, can't start with a number, case-sensitive.
  • type() is your detective — use it whenever you're unsure what type something is.
  • Type conversion: int(), float(), str(), bool() — but only convert values that make sense.
  • f-strings are the best way to print variables inside text. Use them as your default.

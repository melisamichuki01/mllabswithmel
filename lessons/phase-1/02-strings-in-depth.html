01 Defining strings — all the ways
✓
Mark done

🔁 A string is like a bead necklace

Picture a necklace where each bead is a character — a letter, space, number, or symbol. The word "Python" is a necklace of 6 beads: P, y, t, h, o, n. In that exact order. That sequence is what makes it a string.

You can look at any individual bead (indexing). You can cut out a section of beads (slicing). You can count the beads (length). You can rearrange them. But the string itself is just a sequence of characters in a specific order.

A string can be created with single quotes, double quotes, or triple quotes. They all produce the same thing.

🟡 All ways to define a string
# Single quotes and double quotes are identical in Python
a = 'Hello'
b = "Hello"
print(a == b)   # True — they are the same string

# When to use which: use double quotes when your string contains a single quote
message = "It's a great day"   # single quote inside = use double outside
quote = 'She said "hello"'     # double quote inside = use single outside

# Triple quotes — for multi-line strings or large blocks of text
bio = """My name is Kofi.
I am a data analyst.
I work in Accra."""

print(bio)

# The string's length — len() counts every character including spaces
word = "Python"
print(len(word))     # 6
print(len("Hi!"))   # 3
print(len(""))      # 0 — empty string has length 0
Output for bio
My name is Kofi.
I am a data analyst.
I work in Accra.
len() is your most used string function. It tells you how many characters are in a string. You'll use it constantly — to validate user input length, slice strings, and loop through characters.

Concatenation and repetition

Strings support the + and * operators — but they work differently than with numbers.

🟡 Joining and repeating strings
# + joins strings together (concatenation)
first = "Data"
second = " Science"
combined = first + second
print(combined)     # Data Science

# * repeats a string N times
border = "=" * 30
print(border)       # ============================== (30 equals signs)

laugh = "Ha" * 4
print(laugh)        # HaHaHaHa

# IMPORTANT: you cannot concatenate a string and a number directly
age = 28
# print("Age: " + age)       — TypeError! Must convert first
print("Age: " + str(age))  # Age: 28

The string "Python" — positive indices (top) and negative indices (bottom)

🟡 Indexing — accessing individual characters
word = "Python"

# Positive indexing — count from the start
print(word[0])   # P  — first character
print(word[1])   # y
print(word[3])   # h
print(word[5])   # n  — last character (index = length-1)

# Negative indexing — count from the END
print(word[-1])  # n  — last character
print(word[-2])  # o  — second from last
print(word[-6])  # P  — same as word[0]

# Common use: get the first and last character of any string
name = "Nakamura"
print(f"First: {name[0]}, Last: {name[-1]}")   # First: N, Last: a
🚨 IndexError — you went past the end of the string

If you try to access an index that doesn't exist — for example word[10] on a 6-character string — Python throws an IndexError: string index out of range.

The valid range for a string of length n is: 0 to n-1 for positive indexes, and -1 to -n for negative. Any index outside this range causes an error.

Slicing — extracting a portion

If indexing is getting one bead from the necklace, slicing is cutting out a section of beads. Use [start:stop] where start is included and stop is not included.

🟡 Slicing strings
text = "Python is great"
#       0123456789...  (positions for reference)

# [start:stop] — from start UP TO BUT NOT INCLUDING stop
print(text[0:6])    # Python  (positions 0,1,2,3,4,5)
print(text[7:9])    # is
print(text[10:])   # great  (omit stop = go to the end)
print(text[:6])    # Python (omit start = begin from 0)
print(text[:])     # Python is great (whole string)

# [start:stop:step] — third number controls step size
print(text[::2])   # Pto sget — every 2nd character
print(text[::3])   # Ph ra — every 3rd character

# The famous reverse trick: step of -1 goes backwards
print(text[::-1])  # taerg si nohtyP — reversed!

# Practical uses
filename = "report_2024.csv"
extension = filename[-4:]    # .csv — get the last 4 characters
print(extension)
💡 Why does stop not include the character at that index?

This is called exclusive end (or half-open intervals) and it's a Python convention inherited from mathematics. It feels weird at first but it has advantages:

  • text[:n] always gives you exactly n characters. No off-by-one calculation needed.
  • text[:6] + text[6:] perfectly reconstructs the full string with no overlap.
  • The length of a slice [start:stop] is always stop - start.

Once you accept this convention and stop fighting it, it becomes very natural.

🟡 Escape characters in action
# \n creates a new line within the string
poem = "Roses are red,\nViolets are blue,\nPython is cool,\nAnd so are you."
print(poem)

# \t creates a tab — useful for formatting tables
print("Name:\t\tAge:\t\tCity:")
print("Wanjiru\t\t26\t\tNairobi")
print("Kwame\t\t31\t\tAccra")

# Quotes inside strings
print("The professor said, \"Practice every day.\"")
print('Don\'t give up.')

# Windows file paths need double backslashes (or use raw strings)
windows_path = "C:\\Users\\Mel\\Documents"
print(windows_path)   # C:\Users\Mel\Documents

# RAW strings: put r before the quote to treat backslashes literally
raw_path = r"C:\Users\Mel\Documents"
print(raw_path)        # Same output — easier to type
Raw strings (r"..."): When you prefix a string with r, Python treats every backslash as a literal backslash — no escape processing. Extremely useful for Windows file paths and regular expressions (which you'll use in Track A).

04 String methods
✓
Mark done

A method is a function that belongs to a specific data type and is called using dot notation: variable.method(). Strings have dozens of built-in methods. Here are the ones you will actually use regularly.

💡 Methods don't modify the original string — they return a new one

Strings in Python are immutable — they cannot be changed once created. Every string method returns a new string rather than modifying the original.

So name.upper() does not change name. It creates a new uppercase string and returns it. If you want to keep that result, you must assign it: upper_name = name.upper().

Case methods

🟡 Changing case
text = "hello world from python"

print(text.upper())       # HELLO WORLD FROM PYTHON
print(text.lower())       # hello world from python (already lower)
print(text.capitalize())  # Hello world from python (first char only)
print(text.title())       # Hello World From Python (each word)
print(text.swapcase())    # HELLO WORLD FROM PYTHON (flips every case)

# Original string is unchanged
print(text)               # hello world from python

# Practical use: case-insensitive comparison
user_input = "NAIROBI"
print(user_input.lower() == "nairobi")   # True — compare apples to apples

Trimming whitespace

🟡 strip(), lstrip(), rstrip()
# User input often has accidental spaces. strip() removes them.
messy = "   hello there   "

print(messy.strip())    # "hello there"   — removes both ends
print(messy.lstrip())   # "hello there   " — removes left only
print(messy.rstrip())   # "   hello there" — removes right only

# Always strip() user input before comparing or storing it
email = "  mel@mllabs.com  "
clean_email = email.strip()
print(clean_email)      # mel@mllabs.com

Searching within strings

🟡 find(), count(), startswith(), endswith(), in
sentence = "Data science is the future of data work"

# find() — returns the index of the FIRST match, or -1 if not found
print(sentence.find("data"))    # 0 — first "data" starts at index 0
print(sentence.find("future"))  # 26
print(sentence.find("Python"))  # -1 — not found

# count() — how many times does this substring appear?
print(sentence.count("data"))   # 2 — "Data" + "data" ... wait
print(sentence.count("Data"))   # 1 — case-sensitive!

# The 'in' keyword — simplest check: True or False
print("science" in sentence)    # True
print("Python" in sentence)     # False

# startswith() and endswith()
filename = "report_2024.csv"
print(filename.endswith(".csv"))   # True — check file type
print(filename.startswith("rep"))  # True

Replacing and modifying

🟡 replace()
original = "I love Java. Java is great. Java forever."

# replace(old, new) — replaces ALL occurrences by default
updated = original.replace("Java", "Python")
print(updated)
# I love Python. Python is great. Python forever.

# replace(old, new, count) — only replace the first N occurrences
partial = original.replace("Java", "Python", 1)
print(partial)
# I love Python. Java is great. Java forever.

# replace() returns a new string — original is unchanged
print(original)   # I love Java. Java is great. Java forever.

Checking string content

🟡 isalpha(), isdigit(), isalnum(), isspace()
# These check what kind of characters are in the string
# All return True or False

print("hello".isalpha())    # True  — only letters
print("hello1".isalpha())   # False — contains a digit
print("12345".isdigit())    # True  — only digits
print("3.14".isdigit())     # False — decimal point is not a digit
print("abc123".isalnum())   # True  — letters AND digits
print("   ".isspace())       # True  — only whitespace

# Practical use: validate that user typed a number
user_age = "25"
if user_age.isdigit():
    print(f"Age is: {int(user_age)}")
else:
    print("That doesn't look like a valid age")

05 f-strings deep dive
✓
Mark done

f-strings (formatted string literals) are Python's best way to embed variables and expressions directly inside a string. They're cleaner than concatenation, more readable than .format(), and powerful enough to do formatting in-place.

🟡 f-strings — from basics to power features
name = "Amara"
score = 87.654
passed = True

# Basic: embed a variable
print(f"Hello, {name}!")          # Hello, Amara!

# Expressions inside {} — anything that evaluates to a value
print(f"Score + 5 = {score + 5}")  # Score + 5 = 92.654
print(f"Passed: {score >= 50}")    # Passed: True
print(f"Name has {len(name)} letters")  # Name has 5 letters

# Method calls inside {}
print(f"Upper: {name.upper()}")     # Upper: AMARA

# Number formatting with :.Nf  (N decimal places)
print(f"Score: {score:.2f}")        # Score: 87.65 (rounded to 2 dp)
print(f"Score: {score:.0f}")        # Score: 88 (no decimals)

# :, adds comma separators to large numbers
salary = 120000
print(f"Salary: KES {salary:,}")    # Salary: KES 120,000

# Padding: >N right-align, <N left-align, ^N center, in a field of width N
print(f"{'Item':15}{'Price':>10}")    # aligned column headers
print(f"{'Notebook':15}{350:>10}")
print(f"{'Pen':15}{45:>10}")

# Multi-line f-strings
report = f"""
Student: {name}
Score:   {score:.1f}
Passed:  {passed}
"""
print(report)
Python version note: f-strings require Python 3.6 or later. Since your mllabs environment uses Python 3.11, you'll never hit this issue. Just remember the f before the opening quote — forgetting it means Python treats {name} as literal text, not a variable.

06 split() and join()
✓
Mark done

These two methods are among the most used in real data work. split() breaks a string into a list. join() assembles a list back into a string. They're each other's inverse.

🔁 Like chopping and assembling

split() is like chopping a sentence into individual words at every space. You get back a list of pieces.

join() is like reassembling those pieces — gluing them back together with whatever separator you choose. You decide whether the glue is a space, a comma, a hyphen, or nothing at all.

🟡 split() — breaking a string into parts
# split() with no argument splits on whitespace (spaces, tabs, newlines)
sentence = "The quick brown fox"
words = sentence.split()
print(words)   # ['The', 'quick', 'brown', 'fox']

# split(delimiter) splits on a specific character or string
csv_row = "Nairobi,Kenya,EA,Africa"
parts = csv_row.split(",")
print(parts)   # ['Nairobi', 'Kenya', 'EA', 'Africa']

# Access specific pieces after splitting
city = parts[0]
continent = parts[3]
print(f"{city} is in {continent}")  # Nairobi is in Africa

# split(delimiter, maxsplit) — limit how many splits happen
line = "name=Wanjiru=student=2024"
first_split = line.split("=", 1)  # only split once
print(first_split)   # ['name', 'Wanjiru=student=2024']
🟡 join() — assembling parts into a string
# join() syntax: "separator".join(list_of_strings)
# The separator goes BETWEEN each item

words = ["Python", "is", "really", "fun"]

# Join with a space
sentence = " ".join(words)
print(sentence)    # Python is really fun

# Join with a hyphen
slug = "-".join(words)
print(slug)        # Python-is-really-fun

# Join with nothing — collapses everything together
squished = "".join(words)
print(squished)    # Pythonjsreallyfun

# Practical use: building a CSV-formatted string from a list
record = ["Kofi", "28", "Engineer", "Accra"]
csv_line = ",".join(record)
print(csv_line)    # Kofi,28,Engineer,Accra

# IMPORTANT: join only works on a list of STRINGS
# If you have numbers, convert them first
numbers = [1, 2, 3, 4]
# ",".join(numbers)              — TypeError!
result = ",".join(str(n) for n in numbers)
print(result)      # 1,2,3,4
You can now work with strings like a developer. Indexing, slicing, methods, f-strings, and split/join — these tools appear in almost every real Python program. Data cleaning, file processing, API responses — all of it uses strings constantly.

07 Mini challenge
✓
Mark done

🎯 Challenge — String Data Cleaner

You've received dirty data from a form submission. Clean it up using string methods.

🟡 Starting data — run this first
raw_name = "  AMINA OSEI  "
raw_email = "  AMINA.OSEI@GMAIL.COM   "
raw_age = "27"
raw_city = "nairobi,kenya"

1. Clean the name: strip spaces and convert to title case.
2. Clean the email: strip spaces and convert to lowercase.
3. Convert age to integer and calculate birth year (assume current year is 2025).
4. Split the city string on the comma. Print city and country separately.
5. Check if the email contains "@" — print True or False.
6. Print a formatted profile using an f-string with all cleaned values.

🟡 Solution
raw_name = "  AMINA OSEI  "
raw_email = "  AMINA.OSEI@GMAIL.COM   "
raw_age = "27"
raw_city = "nairobi,kenya"

clean_name = raw_name.strip().title()
clean_email = raw_email.strip().lower()
age = int(raw_age)
birth_year = 2025 - age
city_parts = raw_city.split(",")
city = city_parts[0].title()
country = city_parts[1].title()
has_at = "@" in clean_email

print(f"Name:       {clean_name}")
print(f"Email:      {clean_email}")
print(f"Age:        {age} (born ~{birth_year})")
print(f"City:       {city}, {country}")
print(f"Valid email: {has_at}")

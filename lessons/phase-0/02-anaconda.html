01 Why Anaconda instead of plain Python ✓Mark done

🔁 The furnished flat vs the bare walls

Installing Python on its own is like moving into a new flat with bare walls and no furniture. You can live there, but you'll spend weeks sourcing every individual thing separately — and some things won't fit together properly when you do.

Anaconda is the fully furnished flat. Python is already there. The data science toolkit (Pandas, NumPy, Jupyter, Matplotlib, Scikit-learn) is pre-installed and configured so everything works together. You move in on day one and start working.

Anaconda also gives you conda — a tool for managing environments. An environment is an isolated space where a project lives. The packages inside one environment don't interfere with any other project. This matters enormously once you're working on more than one thing at a time, and it's the professional way to work from day one.

💡 What exactly is an environment?

Imagine two projects: one needs Pandas version 1.5, another needs Pandas version 2.0. If you install everything in the same place, they fight over which version is installed, and one of them breaks.

Environments keep them completely separate. Project A lives in its own room with its own furniture. Project B lives in a different room with different furniture. They never see each other. When you switch environments, you're switching rooms.

02 Installing Anaconda ✓Mark done

1

Go to anaconda.com/download

Click the Download button. Anaconda detects Windows automatically. The file is around 800MB — allow a few minutes for the download.

2

Run the installer

Double-click the downloaded .exe file. Accept the license agreement. When asked about installation type, choose Just Me — this avoids permission issues later.

3

Leave "Add to PATH" unchecked

The installer may ask if you want to add Anaconda to your PATH variable. Leave this unchecked. You'll use Anaconda Prompt instead, which handles the PATH correctly on its own.

4

Complete and verify

Click Finish. Search for Anaconda Prompt in the Start menu and open it. A terminal appears with (base) at the start — that confirms Anaconda is running.

On a Mac? Download the macOS installer from the same anaconda.com/download page. The process is nearly identical. Everything in this course works on Mac — just use ls instead of dir in the terminal.

Verify the installation

🟢 Run in Anaconda Prompt
# Check Python is there
python --version

# Check conda is there
conda --version

# See all the pre-installed packages
conda list
Expected output (versions may differ slightly)
Python 3.11.5
conda 23.9.0
🚨 "conda is not recognised" in regular cmd

This is completely normal and expected. Regular Command Prompt doesn't know about conda — only Anaconda Prompt does. Always use Anaconda Prompt for anything Python or conda related. Search "Anaconda Prompt" in your Start menu — it should appear after installation.

03 Creating your mllabs environment ✓Mark done

All your work for this course will live inside a dedicated environment called mllabs. Creating it now means you always have a clean, consistent Python setup for every lesson.

🟢 Run in Anaconda Prompt
# Create the environment — Python 3.11 is current and stable
conda create --name mllabs python=3.11

# Conda will show you what it plans to install and ask to confirm
# Type y and press Enter
# Takes 1-2 minutes

# Activate the environment — switch into it
conda activate mllabs

# Your prompt now starts with (mllabs) — you're inside the environment

# Confirm the right Python version is running
python --version
Your prompt should now look like this
(mllabs) C:\Users\YourName>
Every time you start working: open Anaconda Prompt and run conda activate mllabs before doing anything else. This switches you into the right environment. If you forget, your scripts will run with the wrong Python and packages won't be found.

Useful conda commands

CommandWhat it does
conda activate mllabsSwitch into the mllabs environment
conda deactivateSwitch back to base
conda env listSee all your environments
conda listSee packages in the current environment
conda infoSee detailed info about your current conda setup

04 Installing the core packages ✓Mark done

With mllabs activated, install the libraries you'll use throughout this course. You only need to do this once.

🟢 Run in Anaconda Prompt (with mllabs activated)
# Install all the core data science libraries in one command
conda install pandas numpy matplotlib seaborn jupyter ipykernel

# Type y when prompted
# This downloads and installs several packages — takes 3-5 minutes

# Verify pandas installed correctly
python -c "import pandas; print('Pandas:', pandas.__version__)"

# Verify numpy
python -c "import numpy; print('NumPy:', numpy.__version__)"
Expected output
Pandas: 2.1.0
NumPy: 1.26.0
💡 What are these packages and why do you need them?
  • pandas — the main data analysis library. Everything in Track A uses it.
  • numpy — fast number crunching. Pandas is built on top of it.
  • matplotlib + seaborn — for charts and visualisations in Track A.
  • jupyter — the notebook engine. Lets you run .ipynb files.
  • ipykernel — connects your conda environment to Jupyter so VS Code can find it.
🎯 Mini Challenge — Anaconda

Prove your environment is working:

1. Open Anaconda Prompt and activate mllabs.
2. Run a single Python command that imports pandas, numpy, and matplotlib all at once and prints all three version numbers.
3. Create a second environment called test_env with Python 3.10 and activate it. Check the Python version — it should say 3.10.x, not 3.11.x. Then switch back to mllabs.

🟢 Anaconda Prompt
conda activate mllabs

python -c "import pandas as pd; import numpy as np; import matplotlib; print('pandas:', pd.__version__); print('numpy:', np.__version__); print('matplotlib:', matplotlib.__version__)"

conda create --name test_env python=3.10
conda activate test_env
python --version

conda activate mllabs

The version check in test_env should return Python 3.10.x. Switching back to mllabs should return Python 3.11.x. Two environments, two Python versions — completely isolated from each other.

Anaconda is installed, your mllabs environment exists, and the core data science packages are ready. You now have the same Python setup professional data scientists use.

05 Practice tasks ✓Mark done

Task 01 — Easy

List all your conda environments with conda env list. You should see at least base and mllabs. If you created test_env, it should appear there too.

Task 02 — Easy

Activate mllabs and run conda list. Find pandas in the list. Note the version number and the channel it was installed from.

Task 03 — Medium

Install the requests library into your mllabs environment using pip install requests. Then verify it installed by running python -c "import requests; print(requests.__version__)".

Task 04 — Challenge

Find out: what is the difference between conda install and pip install? When should you use each one? Write your answer in a few sentences — not by searching, but by testing both in your terminal and observing what they do differently.

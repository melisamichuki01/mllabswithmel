01 What is the terminal? ✓Mark done

🔁 In plain life terms...

Your computer has two interfaces: the one with icons and windows that you click around in, and the terminal — where you type short commands and your computer does exactly what you said.

Think of it like the difference between texting someone instructions versus walking over and doing things yourself. The terminal is direct, precise, and — once you get comfortable — much faster than clicking through menus.

Every professional developer uses the terminal every day. You're going to start using it on day one.

The terminal goes by several names depending on the context: command line, command prompt, shell, console. They all refer to the same concept: a text interface to your computer. Don't let the different names confuse you — they're describing the same thing.

💡 Why not just click everything?

Clicking is fine for most things, but it has limits. You can't automate it. You can't repeat a 12-step process in one line. You can't manage Python environments, install libraries, or run scripts from a GUI.

The terminal is where Python actually lives and runs. Every time you run a Python script in this course, you'll do it through the terminal. Getting comfortable here now makes everything else easier.

02 Opening it on Windows ✓Mark done

Windows has a few terminal options. Here's what each one is and which one to use:

TerminalWhat it isUse it for this course?
Command Prompt (cmd)The classic Windows terminal. Simple and reliable.Yes — for general navigation
PowerShellMore powerful than cmd, supports more commands.Yes — same as cmd for our purposes
Anaconda PromptA special terminal that comes with Anaconda. Has Python and conda ready to use.Yes — use this once Anaconda is installed
Windows TerminalA modern tab-based terminal. Optional.Fine to use if you prefer it
For now: use Command Prompt or PowerShell. Once you install Anaconda in lesson 0.2, switch to Anaconda Prompt for all Python-related work.

Opening Command Prompt

1

Press the Windows key

The key with the Windows logo on it — between Ctrl and Alt on the bottom left of your keyboard.

2

Type cmd or powershell

Start typing immediately. You don't need to click anywhere. The search results appear instantly.

3

Press Enter

A dark window opens with a blinking cursor and text like C:\Users\YourName>. That's your terminal. It's waiting for a command.

🚨 Don't worry — this window looks intimidating at first

A blank black window with a blinking cursor is not an emergency. You cannot break your computer by typing commands here. The worst that happens is you get an error message — and error messages are just the terminal telling you what went wrong so you can fix it.

The cursor is simply waiting for you to type. Treat it like a chat window where you give instructions.

03 The 5 commands you actually need ✓Mark done

You don't need to memorise hundreds of commands. Here are the five that matter right now — and you'll use these every day.

CommandWhat it doesReal example
cd foldernameMove into a folder (cd = "change directory")cd Documents
cd ..Go back up one folder level (two dots = one level up)cd ..
dirList everything inside the current folderdir
mkdir foldernameCreate a new folder (mkdir = "make directory")mkdir my_project
cdOn its own, shows you where you are right nowcd

Try them now

Open your terminal and run these commands one by one. Don't copy-paste them — type them. Typing is how you build muscle memory.

🟢 Run in Terminal — type each line, press Enter after each one
REM Check where you are right now
cd

REM Move into your Documents folder
cd Documents

REM See what's inside
dir

REM Create a folder for this course
mkdir mllabs

REM Move into that new folder
cd mllabs

REM Confirm where you are
cd
After running cd at the end, you should see something like this
C:\Users\YourName\Documents\mllabs
💡 What's REM in the code above?

REM is a comment in Windows terminal — the terminal ignores it completely. It's just a note for you to read. You don't need to type the REM lines — just the actual commands below each one.

In Python scripts you'll use # for comments. In the Windows terminal it's REM. In Mac/Linux terminals it's also #. Different tools, same idea.

Going backwards and sideways

🟢 More navigation to practise
REM Go up one level (back to Documents)
cd ..

REM Go up two levels at once
cd ..\..

REM Jump directly to a full path
cd C:\Users\YourName\Documents\mllabs

REM Go directly to your Desktop
cd %USERPROFILE%\Desktop
%USERPROFILE% is a Windows shortcut that means "the current user's home folder." So %USERPROFILE%\Desktop translates to C:\Users\YourName\Desktop automatically — whatever your username is.

04 Understanding paths ✓Mark done

🔁 Think of it like a building address

A path is the address of a file or folder on your computer. Just like a postal address tells you: country → city → street → house number, a file path tells your computer: drive → folder → subfolder → file.

C:\Users\Mel\Documents\mllabs\hello.py

Read left to right: C drive → Users folder → Mel's folder → Documents → mllabs → hello.py

Absolute vs relative paths

There are two ways to describe where something is:

TypeWhat it meansExample
Absolute pathThe full address from the drive root. Works from anywhere.C:\Users\Mel\Documents\mllabs
Relative pathThe address relative to where you are right now. Shorter, but depends on your current location.Documents\mllabs (if you're in C:\Users\Mel)
🚨 "No such file or directory" — the most common beginner error

When you see this error, it almost always means one of three things:

  • Typo in the folder name — folder names are case-sensitive on some systems and must be spelled exactly. Check with dir to see the real name.
  • You're in the wrong place — run cd to see where you are. You might be trying to navigate into a folder that doesn't exist at your current location.
  • The folder doesn't exist yet — you need to create it first with mkdir.

Spaces in folder names

If a folder name contains a space (like My Documents), wrap the whole path in quotes:

🟢 Terminal
REM This fails — the terminal thinks "My" and "Documents" are two separate things
cd My Documents

REM This works — quotes keep it together
cd "My Documents"
Pro habit: avoid spaces in folder and file names for anything Python-related. Use underscores instead: my_project not my project. This prevents a whole class of annoying errors before they start.

05 Mini challenge ✓Mark done

🎯 Terminal Challenge — Navigate and Build

Using only the terminal — no mouse, no File Explorer — complete all four steps:

1. Navigate to your Desktop.
2. Create a folder called python_work.
3. Inside python_work, create another folder called phase_0.
4. Navigate into phase_0 and confirm your full path.

🟢 Terminal
cd %USERPROFILE%\Desktop
mkdir python_work
cd python_work
mkdir phase_0
cd phase_0
cd

The final cd should print something like:
C:\Users\YourName\Desktop\python_work\phase_0

If you see that path, you navigated correctly using only the terminal.

You can navigate your computer using text commands. That's a skill most people never learn. You just did it in your first lesson.

06 Practice tasks ✓Mark done

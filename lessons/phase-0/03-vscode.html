01 Why VS Code? ✓Mark done

🔁 The difference between Notepad and a proper word processor

You could write Python code in Notepad — it's just text, and it would technically work. But that would be like writing a dissertation with a pencil stub on napkins. It works, but you're making things hard for yourself unnecessarily.

VS Code is a proper word processor for code. It colour-codes your syntax so errors stand out immediately. It spots mistakes before you run anything. It lets you see all your project files, run the terminal, debug code, and use notebooks — all in one window. Free, fast, and what most professional Python developers actually use.

There are other good editors — PyCharm, Sublime Text, Notepad++. But VS Code has the best balance of power and simplicity for beginners, and its Python and Jupyter extensions are maintained by Microsoft themselves. It's the default recommendation for this course.

02 Installing VS Code and extensions ✓Mark done

Installing VS Code

1

Go to code.visualstudio.com

Click the big blue Download button. VS Code detects Windows and downloads the right installer automatically.

2

Run the installer

Accept the agreement. On the "Select Additional Tasks" screen, tick "Add to PATH" and both "Open with Code" context menu options. Leave everything else as default.

3

Open VS Code

It opens automatically after installation. You'll see a Welcome tab — close it. You're now inside VS Code.

Installing the three extensions you need

Extensions are optional add-ons that give VS Code new capabilities. You need exactly three for this course:

ExtensionPublisherWhat it does
PythonMicrosoftCore Python support: syntax highlighting, running scripts, interpreter selection
PylanceMicrosoftSmart autocomplete, real-time error detection as you type, type hints
JupyterMicrosoftRun .ipynb notebook files directly inside VS Code, no browser needed
1

Open the Extensions panel

Click the square icon on the left sidebar (four squares, one slightly detached). Or press Ctrl + Shift + X.

2

Install Python

Search "Python". The first result should be "Python" by Microsoft. Click Install. Pylance usually installs automatically alongside it.

3

Install Jupyter

Search "Jupyter". Install the "Jupyter" extension by Microsoft. This gives you notebook support inside VS Code.

Already installed? If VS Code suggests updates for any extension, install them. Keep extensions current — bugs get fixed and new Python features get added.

03 Selecting your Python interpreter ✓Mark done

VS Code needs to know which Python to use when it runs your code. You have Anaconda installed with a mllabs environment — point VS Code at that one.

1

Open the Command Palette

Press Ctrl + Shift + P. This is VS Code's search bar for every feature and setting — you'll use it constantly.

2

Search "Python: Select Interpreter"

Type that phrase and click it when it appears in the dropdown.

3

Choose the mllabs environment

You'll see a list of Python installations. Find the one that says conda: mllabs or shows a path containing mllabs. Click it.

The interpreter you're looking for looks like this
Python 3.11.5 ('mllabs': conda)
~\anaconda3\envs\mllabs\python.exe

After selecting, check the bottom status bar of VS Code. It should now show the Python version and environment name on the left side. That's your confirmation it worked.

🚨 My mllabs environment isn't in the list

This sometimes happens when VS Code opens before the Anaconda environment is fully registered. Try this fix: close VS Code, open Anaconda Prompt, run conda activate mllabs, then type code . and press Enter. This opens VS Code from within the activated environment and it should recognise it immediately.

04 Opening folders and the integrated terminal ✓Mark done

Always open a folder in VS Code, not a file. Opening a folder gives VS Code full context about your project — it knows where all your files are, where the terminal should start, and how everything relates.

1

File → Open Folder

Or press Ctrl + K, Ctrl + O. Navigate to your mllabs folder in Documents and click Select Folder.

2

Trust the folder

VS Code may ask "Do you trust the authors of the files in this folder?" — click Yes. This enables all features for that workspace.

3

Open the integrated terminal

Press Ctrl + ` (the backtick key — top left of your keyboard, above Tab). A terminal panel opens at the bottom, already pointed at your project folder.

Build this habit now: always open VS Code by opening a folder, not a file. It keeps your workspace organised, your terminal in the right place, and your interpreter settings consistent.
💡 The integrated terminal vs Anaconda Prompt

The terminal inside VS Code is just a regular terminal — by default it opens as Command Prompt or PowerShell on Windows. It does NOT automatically activate your conda environment.

You still need to run conda activate mllabs in the integrated terminal before running Python scripts. Alternatively, VS Code has a setting to activate the selected environment automatically — look up "Python: Terminal Activate Environment" in your settings if you want to enable it.

05 Shortcuts every Python developer uses ✓Mark done

Learn these now. They become muscle memory quickly and save enormous amounts of time:

Ctrl + Shift + P

Command Palette — search any VS Code feature or setting

Ctrl + `

Open / close the integrated terminal

Ctrl + S

Save the current file

Ctrl + /

Toggle a line as a comment

F5

Run the current Python file with the debugger

Ctrl + Shift + `

Open a new terminal tab

Alt + ↑ / ↓

Move a line of code up or down

Ctrl + D

Select the next occurrence of the word your cursor is on

🎯 Mini Challenge — VS Code Setup Check

Complete this setup verification from inside VS Code:

1. Open your mllabs folder in VS Code.
2. Create a new file called setup_check.py.
3. Write a script that prints your name, today's date using the datetime module, and the pandas version.
4. Open the integrated terminal, activate mllabs, and run the script.
5. Confirm the bottom status bar shows the mllabs interpreter.

🟡 setup_check.py
from datetime import date
import pandas as pd

print("Name: Mel")
print(f"Date: {date.today()}")
print(f"Pandas: {pd.__version__}")
🟢 Integrated Terminal
conda activate mllabs
python setup_check.py

If all three lines print without error, your VS Code setup is fully working.

VS Code is installed, connected to your Anaconda environment, and you know the shortcuts that make you fast. You have a proper coding workspace.

06 Practice tasks ✓Mark done

Task 01 — Easy

Open your mllabs folder in VS Code. Create a new Python file. Write one print statement. Run it from the integrated terminal. Confirm the output appears.

Task 02 — Easy

Use Ctrl + / to comment out a line of code in your Python file. Then uncomment it. Then use Alt + ↓ to move that line down. These two shortcuts alone save hours over a course.

Task 03 — Medium

Open the VS Code settings (Ctrl + ,). Search for "Format On Save" and enable it. Search for "Python: Default Interpreter Path" and confirm it points to your mllabs environment.

Task 04 — Challenge

Install the GitLens extension. Open a Python file and hover over a line. GitLens shows you the last git commit that touched that line. You don't need a git repo set up yet — just install the extension and explore the interface. We'll use it properly in Phase 7.

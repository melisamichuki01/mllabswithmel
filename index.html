How to use this series

STEP 01

Go in order. Each lesson builds on the last. Don't skip ahead.

STEP 02

Open a Python environment alongside each lesson -- Jupyter, Colab, or VS Code all work.

STEP 03

Do every mini challenge. Reading isn't enough -- you have to type the code yourself.

STEP 04

Mark lessons done when you can explain the concept out loud without looking at notes.

Before you start: Make sure Python is installed on your machine, or open a free Google Colab notebook. You don't need to install anything to get going.

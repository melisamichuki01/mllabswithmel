How to use this curriculum

Three things to know before you start

This is not a shortcut. It is a complete Python education. If you want to be good, this is the work. Here is how to get the most out of it.

1

Read first, code second

Each page explains one concept using analogies before code. Read it fully before running anything. Understanding why before how makes everything stick.

2

Do every mini challenge

Every section has a challenge with a collapsible answer. Try it yourself first. The answer is there for when you are genuinely stuck, not as a shortcut.

3

Mark done when you can explain it

Tick a phase off when you can explain it out loud without notes. Not when you have read it. When you can teach it. That is the bar.

Go in order. Each phase builds directly on the last. If something in Phase 3 confuses you, the answer is almost always in Phase 1 or 2.

Before you start

How to set yourself up

There are two ways to work through this curriculum. The first is the proper developer setup: everything installed on your machine, working the way a real Python developer works. The second is a lightweight alternative if you cannot or do not want to install anything yet.

Recommended

🖥️ Local Setup with Anaconda

Anaconda installs Python, a package manager, and the most important data science libraries in one step. It also handles environments properly so your projects do not clash with each other.

  • Download Anaconda from anaconda.com
  • Run the installer and follow the prompts
  • Install VS Code as your editor
  • Add the Python and Jupyter extensions in VS Code
  • Open the terminal and verify with conda --version

Phase 0 of this curriculum walks you through every step. You will not be doing this alone.

Lightweight Alternative

☁️ Google Colab

If your machine is low on storage, slow, or you just want to start writing code today with zero installation, Colab works. All you need is a Google account.

  • Go to colab.research.google.com
  • Sign in with your Google account
  • Create a new notebook: Python is already there
  • Files save to Google Drive automatically

Colab is great for getting started but it has limits: no persistent file system, sessions time out, and it does not teach you how to work like a developer. Move to local setup when you can.

Something you will come across immediately

What are .py and .ipynb files?

When you start working with Python you will see two file types everywhere. They are both Python but they work differently and get used in different situations.

.py

A Python script

A plain text file containing Python code. You run it from the terminal or VS Code and it executes top to bottom. This is what most real Python projects are made of: automations, APIs, tools, applications.

When to use it: Building something that runs, automates, or serves other people.

.ipynb

A Jupyter Notebook

A notebook made up of cells. Write and run code one block at a time, see outputs inline, mix code with notes, and explore data interactively. The format Colab uses. Common in data science and analysis work.

When to use it: Exploring data, experimenting, teaching, or showing your work step by step.

Quick rule: Exploring or analysing data, use a notebook. Building something that runs on its own, use a script. Most data scientists use both regularly.

How to write and run a Python file in Colab

Colab is notebook-first, but you can write and think in terms of scripts. Here is the pattern:

1

Open a new notebook

Go to colab.research.google.com, click "New notebook". You will see an empty cell ready for code.

2

Write your Python code in a cell

Each cell is like one block of a script. Write your code, press Shift + Enter to run it. Output appears directly below.

3

Save it as a real .py file using %%writefile

Put %%writefile filename.py at the top of a cell. Everything in that cell gets saved as an actual Python script.

🟡 Write this in a Colab cell
%%writefile my_first_script.py

# This saves the cell as a .py file
print("Hello from my first Python script")

name = "Mel"
print(f"Welcome, {name}. Let's build something.")
🟡 Then run it with this in the next cell
%run my_first_script.py
Output
Hello from my first Python script
Welcome, Mel. Let's build something.
Note: Files created with %%writefile only exist for the duration of your Colab session. When it ends, they are gone. Save important work to Google Drive or download it to your machine.
